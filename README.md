# WashFlow Kiosk

ระบบ Kiosk สำหรับร้านซักผ้าอัตโนมัติ พัฒนาด้วย Visual Basic และ Windows Forms บน .NET 10

## ความสามารถ

- เลือกเครื่องซักผ้าและโปรแกรมซัก
- แสดงสถานะเครื่องและเวลาคงเหลือ
- ออกคิวชำระเงิน
- รองรับ QR PromptPay และการรับเงินสดพร้อมคำนวณเงินทอน
- เปลี่ยนสถานะเครื่องหลังชำระเงิน

## เริ่มใช้งาน

เปิด `film.slnx` ด้วย Visual Studio 2026 หรือใช้คำสั่ง:

```powershell
dotnet run --project film/film.vbproj
```
